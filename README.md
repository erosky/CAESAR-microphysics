This preliminary dataset contains a best estimate of cloud microphysical parameters from CAESAR. The dataset is constructed using a combination of all the available in-situ cloud probes on board the C-130 aircraft. By analyzing the agreement between probes, and selecting appropriate probes for specific particle size ranges, we obtain particle concentration estimates across the full particle size spectrum from 2um to 19mm, and PRELIMINARY uncertainty bounds on these data.

See README_CAESAR_MICROPHYSICS.pdf for further documentation.
