These files are used to construct the CAESAR Cloud Microphysics Value Added Product. The resulting preliminary dataset contains a best estimate of cloud microphysical parameters from CAESAR. The dataset is constructed using a combination of all the available in-situ cloud probes on board the C-130 aircraft. By analyzing the agreement between probes, and selecting appropriate probes for specific particle size ranges, we obtain particle concentration estimates across the full particle size spectrum from 2um to 19mm, and PRELIMINARY uncertainty bounds on these data.

The resulting data product (Netcdf files) can be requested from the EOL data archive: https://data.eol.ucar.edu/dataset/391197

See README_CAESAR_MICROPHYSICS.pdf for further documentation.
